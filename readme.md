## Calendar Sync from Outlook ICS to Google Drive

I made this so i can have my outlook work calenadar in the other work google calendar.

Just run npm build, run, bla bla you know what do do...

Here are the environment variables:

```
# outlook calendar ICS url
OUTLOOK_ICS_URL=http://blabla.com
# google calendar id, if its your account then your email will be it
GOOGLE_CAL_ID=ecodini@kovix-group.com
# key file, located at the keys folder in the project root
GOOGLE_CAL_KEY=google-calendar.json
```

Have fun!
